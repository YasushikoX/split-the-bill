# **App Name**: Split The Bill

## Core Features:

- Session Creation: Create a new bill splitting session with a unique, shareable link.
- Item Input: Add items to the bill with their name and price.
- Item Removal: Remove items from the bill.
- Consumption Assignment: Assign specific items to individual participants.
- Icon Assignment Tool: Automatically assign icons to bill items based on keywords in their names.
- Fair split Calculation: Calculate a fair split for each participant in realtime.
- Shareable Link: Generate a shareable link, to invite everyone

## Style Guidelines:

- Primary color: Mountbatten Pink (#9E829C) for a subdued, calming feel.
- Background color: Ghost White (#F0EFF4) for a clean, uncluttered appearance.
- Accent color: Dark Purple (#30011E) to create contrast for actionable elements
- Font Pairing: 'Poppins' (sans-serif) for headings and short amounts of text, 'PT Sans' (sans-serif) for the body.
- Simple, clear icons to represent item categories. The system should suggest an appropriate icon for an item using an AI 'tool' (but without the user selecting them), falling back to a generic icon if none are relevant.
- Clean and intuitive layout with clear sections for adding items, assigning consumption, and viewing the split.
- Subtle animations when adding or removing items and when calculating the split.
